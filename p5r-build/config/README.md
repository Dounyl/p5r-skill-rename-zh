# 改名配置

`changes.json` 是当前版本唯一的改名规则来源。只保留 `changes` 列表，版本号来自 ModConfig，校验值由构建自动生成。

每条规则包含名称表分组 `section`、条目 `id`、原名 `old` 和新名 `new`。两组技能名称（1、2）及技能卡（14）需要分别维护；编号不可互换。恢复原名时删除规则。

`P5R-命名范围审查.md` 是历史决策参考，不是当前构建输入。实际名称以 `changes.json` 为准。

`naming-guide.md` 是面向玩家的规则说明，构建时填入当前版本并输出为 Mod 内的「技能名称对照表.md」。修改改名规则时同步维护这份说明；它不参与名称表生成。
