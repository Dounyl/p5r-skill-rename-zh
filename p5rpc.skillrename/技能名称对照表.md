# 技能去异味：名称修改说明

对应版本：**0.4.4**。

技能与技能卡片使用同一套命名规则。下面统一说明哪些名称改了、改成什么，以及哪些保持原样。

**对话中提到的技能名称没有修改，仍使用原版名称，可能与界面显示不同。技能效果和数值也没有改变。**

## 攻击技能：属性、强度和作用范围写进名称

常见元素攻击采用「属性＋等级」；群体技能加上「群体」。Ⅰ、Ⅱ、Ⅲ、Ⅳ用于区分对应的伤害档次，不代表修改了威力。

| 原来的名称 | 修改后 | 规则 |
|---|---|---|
| 亚基／亚基拉欧／亚基达因 | 火焰Ⅰ／火焰Ⅱ／火焰Ⅲ | 同系列按强度区分 |
| 布芙／加尔／吉欧 | 冰冻Ⅰ／疾风Ⅰ／电击Ⅰ | 音译改为属性名称，后续等级沿用同样形式 |
| 赛／芙雷／克哈／耶哈 | 念动Ⅰ／核热Ⅰ／祝福Ⅰ／诅咒Ⅰ | 直接体现属性 |
| 玛哈拉基／玛哈拉基翁／玛哈拉基达因 | 群体火焰Ⅰ／群体火焰Ⅱ／群体火焰Ⅲ | 群体范围明确标出，其他元素同理 |
| 炼狱／大燃烧 | 火焰Ⅳ／群体火焰Ⅳ | 部分已有中文名的高阶攻击也统一为效果名称 |
| 米吉多／米吉多拉／米吉多拉翁 | 群体万能Ⅱ／群体万能Ⅲ／群体万能Ⅳ | 万能攻击也区分强度 |
| 哈玛／哈玛翁 | 祝福即死Ⅰ／祝福即死Ⅱ | 即死技能区分成功率档次，群体版本加「群体」 |
| 姆多／姆多翁 | 诅咒即死Ⅰ／诅咒即死Ⅱ | 同上 |
| 神之审判／恶魔审判 | 生命减半(祝)／生命减半(咒) | 特殊效果直接写明 |

## 异常技能：直接说明施加哪种状态

异常技能用状态名和成功率档次表示；这里的数字表示成功率档次，不是伤害，也不表示同档技能概率完全相同。

| 原来的名称 | 修改后 |
|---|---|
| 普林帕／颠塔拉弗 | 混乱Ⅲ／群体混乱Ⅱ |
| 致盲／黑夜闪光 | 晕眩Ⅲ／群体晕眩Ⅱ |
| 永眠／摇篮曲 | 睡眠Ⅲ／群体睡眠Ⅱ |
| 马琳卡琳／精神污染 | 洗脑Ⅲ／群体洗脑Ⅱ |

恐惧、遗忘、饥饿、狂怒和绝望等已改名技能也采用对应状态名称。

## 统一符号：ＵＰ改为↑

名称中的「ＵＰ」统一替换为「↑」，例如「晕眩概率ＵＰ → 晕眩概率↑」「暴击率大ＵＰ → 暴击率大↑」。

多数此类名称只替换符号，保留原有措辞；「哈玛成功率ＵＰ」「姆多成功率ＵＰ」同时改为「祝福即死成功率↑」「诅咒即死成功率↑」。

## 哪些保持原样

- **物理、枪击主动攻击的名称**保持原样；上面列出的辅助技能另按效果命名。
- **防御墙名称**保留，例如「防炎之壁」。
- **强化与增伤被动名称**保留，例如「疾风强化」「高级疾风强化」「魔导才能」。名称中含「ＵＰ」的仍按统一符号规则处理。
- **消除属性防御类名称**保留，例如「消除火焰防御」。
- **「救世主之愈」**保留原名。
- 其他不在改名范围内的名称不动，不额外添加专用技能标签。
- **对话中的技能名称、技能效果和数值均不修改。**
