# 技能去异味 0.4.4

适用于《女神异闻录 5 皇家版》PC Xbox 版简体中文。

技能与技能卡片使用同一套命名规则：将部分名称改为易懂的效果名称，例如「亚基 → 火焰Ⅰ」「提特拉康 → 物理反射」，并将名称中的「ＵＰ」统一为「↑」。

防御墙、强化与增伤、消除属性防御及「救世主之愈」等名称保留原样；其中的「ＵＰ」仍按统一符号规则处理。只改名称，不改技能效果或数值。

**对话中提到的技能名称未作修改，仍使用原版名称，可能与技能和技能卡片显示的名称不同。**

哪些名称改了、改成什么、哪些保持原样，见 [名称修改说明](技能名称对照表.md)。

## 使用与更新

需要 Reloaded-II、Persona Essentials 和 CriFs V2 Hook。将安装包内的 `p5rpc.skillrename` 文件夹放入 Reloaded-II 的 Mods 目录，启用本 Mod 及依赖。
更新前关闭游戏，将新版覆盖到原 Mod 文件夹，再重新启动游戏。

本 Mod 使用完整名称表覆盖，不能与其他修改同一名称表的 Mod 自动合并。
