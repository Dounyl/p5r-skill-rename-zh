# P5R 技能去异味

《女神异闻录 5 皇家版》（P5R）简体中文技能改名 Mod，让技能名称更直观、更容易理解。

## 做了什么

- 将选定的音译技能名改为表达效果的名称，例如「亚基 → 火焰Ⅰ」。
- 同步调整对应的技能卡名称。
- 统一部分名称的表达，例如「物理反射」「魔法反射」，以及将名称中的「ＵＰ」统一为「↑」。
- 保留部分原有名称，例如防御墙、强化与增伤被动，以及「救世主之愈」。

本 Mod 修改技能和技能卡片的名称，不改变技能效果或数值。**对话中提到的技能名称未作修改，仍使用原版名称，可能与技能和技能卡片显示的名称不同。**

当前版本为 **0.4.4**，涉及 188 个技能 ID，共调整 362 条技能名称记录和 160 条技能卡名称，合计 522 条。

完整改名内容见 [最终名称对照表](p5rpc.skillrename/技能名称对照表.md)。

## 项目结构

```text
项目/
├─ README.md              项目介绍
├─ .gitignore             文件收录规则
├─ changelog/             按版本保存的更新说明
├─ p5r-build/             开发与维护内容
│  ├─ src/               加载器源码
│  ├─ scripts/           制作、检查与发布流程
│  ├─ config/            改名规则
│  ├─ vendor/            本地第三方材料
│  ├─ input/             原始游戏资源
│  ├─ temp/              临时产物与本地归档
│  └─ dist/              发布安装包
└─ p5rpc.skillrename/     Mod 本体、使用说明与名称对照表
```

`p5r-build/` 用于维护项目源码和改名内容，保存制作、检查与整理 Mod 所需的材料。

`p5rpc.skillrename/` 用于整理面向玩家的 Mod 内容，包括 Mod 配置、说明和最终名称对照表。

仓库用于维护项目；可直接使用的完整 Mod 安装包通过 **Releases** 提供下载。发布文件、本地备份和临时文件不纳入仓库。

历史更新见 [更新日志](changelog/README.md)。
